Project Overview

A four-month consultancy for AHA! Behavioral Design focused on designing and implementing a centralized Asset Management System and governance framework using Google Workspace and Google Apps Script.

01

The Challenge

The engagement required a clearer operating model for assets, repositories, document ownership, permissions, sensitive information, and repeatable workflows. The goal was not only to build a tool, but to establish governance around how information should be organized, accessed, maintained, and handed over.

02

The Solution

Designed the repository architecture and governance logic, implemented a centralized AMS, structured role access using RACI and RBAC concepts, introduced metadata and controlled configuration, and supported documentation, training, and formal system turnover.

Core Capabilities

  • Centralized asset and repository management
  • Google Drive repository architecture
  • RACI and role-based access governance
  • User management and controlled permissions
  • Metadata and file version management
  • Controlled dropdowns and checklist values
  • SBI Masters Library and repository workflow
  • Governance structure for sensitive records
  • Documentation, training, and formal system turnover
